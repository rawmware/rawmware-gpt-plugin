# v2 research brief: 2026-10-02

**Question:** What should v2 of the operator add to be multi-purpose, current and worth sharing, and what are the platform facts it must get right?

## Answer
Ship it as both a ChatGPT app (MCP + Apps SDK widget) and a Custom GPT (Actions). Route work to ChatGPT built-ins first. Add social, trends, design-taste, project memory and plugin-to-plugin calls. Keep knowledge in live playbooks instead of the 8k instructions.

## Evidence
- Apps SDK: tools point at a UI template via `_meta["openai/outputTemplate"]`; the resource uses MIME `text/html+skybridge`; `structuredContent` hydrates the widget; `openai/toolInvocation/invoking|invoked` set status text. MCP Apps standard is moving to `text/html;profile=mcp-app`. Sources: https://mcpui.dev/guide/apps-sdk · https://developers.openai.com/apps-sdk/reference · https://sunpeak.ai/blogs/migrate-openai-apps-sdk-to-mcp-apps/
- Instagram: **5-hashtag hard cap** (since Dec 2025, caption + first comment); caption 2,200 chars, ~125 visible. Sources: https://www.lilachbullock.com/instagram-hashtag-limit/ · https://www.sendible.com/insights/instagram-character-limit
- Instagram Reels: 1080×1920 9:16; record ≤3 min, upload ≤15 min; reach drops past 3 min; safe zones ~250px top / ~350px bottom. Sources: https://www.socialcal.app/blog/instagram-video-length-limits-2026 · https://postfa.st/sizes/instagram/reels
- TikTok: caption 2,200 (API, UTF-16), ~80–100 visible; in-app ≤10 min, upload ≤60 min; oEmbed is keyless (`https://www.tiktok.com/oembed?url=`). Sources: https://developers.posteverywhere.ai/platforms/tiktok · https://developers.tiktok.com/doc/embed-videos
- Public MCP servers: DeepWiki `https://mcp.deepwiki.com/mcp` (no auth); Context7 `https://mcp.context7.com/mcp` (key optional; tools `resolve-library-id`, `query-docs`). Sources: https://mcpservers.org/servers/devin/deepwiki · https://github.com/upstash/context7

## Unknowns
- Exact ChatGPT Free-tier quotas for built-in tools change often; the GPT tells users when a feature needs a paid plan instead of asserting numbers.
- Instagram oEmbed needs a Meta app token; without it, `social` falls back to og-meta scraping (best effort; Instagram may serve a login wall).
- Reddit's JSON endpoints often block datacenter IPs; `trends source:all` excludes Reddit by default.

## Decision
Build v2 as above: zero runtime dependencies, one schema source, live playbooks and registry, weekly CI self-check. Because: it maximizes value per token, keeps server costs near zero, and every improvement ships through the GitHub repo, so the repo itself shows the work.
