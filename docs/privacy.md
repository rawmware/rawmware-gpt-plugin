# Privacy Policy: rawmware Operator

- The service receives only the arguments the GPT sends to a tool call (URLs, repo names, search queries).
- It fetches public web pages and public GitHub/Vercel data on your behalf and returns the result. Nothing is sold or shared.
- Requests are not stored beyond standard hosting logs (Vercel), kept per Vercel's retention.
- Write tools (`docs_write`, `plugins_propose`) only work for the owner's API key and only write to the owner's repository.
- Contact: open an issue at https://github.com/rawmware/rawmware-gpt-plugin/issues
