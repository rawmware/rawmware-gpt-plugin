# Social content: Instagram, TikTok, Shorts, X, LinkedIn

For anyone producing short-form content (devs, founders, brands). Current specs live in `social op:specs` (updated in the repo). This playbook is the *how*.

## What works for dev/AI content (2026)
- **Show the result in second 0–2**, then how. "I built X" is weak; the finished thing doing something surprising is strong.
- **Before → after**: broken deploy → green in 40s; ugly site → audited → fixed.
- **Real numbers on screen**: time saved, tokens saved, score 54 → 92.
- **Build-in-public series** beats one-off virality: "Day 12 of 365 days of programming" builds a following that compounds.
- **Faces + screens**: a 2-second face intro then screen recording retains better than screen-only.
- **Talk like a person.** Plain words, no buzzwords. Your story (self-taught, shipping daily) IS the hook.

## Short-form video script template
```
HOOK (0–2s):   on-screen text + first spoken line = the payoff. "This GPT fixed my broken deploy in 30 seconds."
CONTEXT (2–6s): the problem, one line.
DEMO (6–40s):  3–5 fast cuts of it working. Zoom in. No dead air.
PROOF (40–50s): the number / the result / the before-after.
CTA (last 3s): one ask only: "Link in bio" / "Comment GPT and I'll send it" / "Follow for day 13."
```
Shot list: cursor highlights on, zoom 150%+, crop to the action, captions burned in, safe zones respected.

## Captions & hashtags
- Instagram: first ~125 chars are visible: put the hook + keyword there. **Max 5 hashtags** (hard cap since Dec 2025, caption + first comment combined).
- TikTok: first ~80–100 chars visible. Captions are search: write the words people type ("custom GPT tutorial", "vercel deploy error").
- 3–5 specific tags > broad ones: #buildinpublic #chatgpt #webdev #vibecoding #ai.

## Formats by platform
- **IG Reels / TikTok / Shorts**: 9:16, 1080×1920, 20–45s sweet spot for demos.
- **IG carousel**: up to 20 slides. Slide 1 hook, slides 2–8 one idea each, last slide CTA. Great for "5 tools I use", "my design token system".
- **X**: one-line hook + 15–40s clip, or a thread: hook, 5 steps, link.
- **LinkedIn**: story post (problem → what I built → result → lesson), first ~210 chars matter.

## Weekly content system (from one shipped feature)
1. Mon: demo Reel/TikTok (the result).
2. Tue: X thread (how it works).
3. Wed: carousel (the lesson / framework).
4. Thu: behind-the-scenes or failure story.
5. Fri: LinkedIn post + repo link.
Repurpose one recording five ways. Use ChatGPT Image Gen for thumbnails and carousel slides (included in the user's plan).

## Analyzing a post or creator
`social op:post url:…` / `op:profile` → note: hook (first line/frame), length, format, posting cadence, engagement relative to followers. Copy the *structure*, never the content.
