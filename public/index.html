The loop

Every non-trivial task runs the same five steps. Skip what adds nothing.

ScrapeRead the page, repo, deploy log or post. Never guess what can be read.
ResearchPast notes first, then live docs (Context7, DeepWiki) and the web.

AnalyzeOne recommendation, the reason, the risk.

Built for the jobs that block you

Each tool trims its output at the source and does in one call what usually takes five.

github op:run_logs

Latest failed CI run → failed step → first real error with context.

vercel op:logs

Latest failed deployment → first build error. Your token, your projects.

github op:pr

Diff, CI checks and review state in one call; inline review comments back.

github op:grep

Regex across any repo or branch, private included. No clone.

github_write op:pr

Branch, commit N files, open the PR. Re-run to push more commits to it.

deps op:audit

OSV vulnerabilities with fixed versions, outdated majors, deprecations. npm, PyPI, crates, Go.

libdocs

Current, version-specific docs: Context7, then llms.txt, then official docs.

site op:health

TTFB cold/warm, caching, compression, security headers, blocking scripts, SEO.

site op:crawl

Scoped crawl of a docs section: matching lines only, broken pages, slowest pages.

research · web_fetch

Search with provider fallback, parallel reads, code blocks kept verbatim.

github op:audit

Stack, CI status, tests, lockfile, committed secrets: gaps ranked by severity.

plugins · plugin_call

ChatGPT built-ins, OpenAI APIs, MCP servers: picks the right one, calls public ones.

Fewer tokens, better answers

Tool output is paid for in money, plan limits and model attention. A raw API response is 5–20× bigger than the useful part, and long, noisy context makes models worse.

  • findOnly matching lines from a page, not the whole page.
  • linesRead lines 40–90 of a file, not 2,000.
  • auditOne call replaces six.
  • playbookKnowledge loads per section, only when a task needs it.
  • cacheRepeat reads are free and instant.

Your plan, used fully

Inside ChatGPT, the operator routes work to built-ins you already pay for: Web Search, Deep Research, Python, Image Gen, Canvas and Agent. Its own server does only what ChatGPT can't do alone.

  • builtinBroad search, reports, data, images: covered by your plan.
  • operatorGitHub, Vercel, page-level scraping, design, social, registry.
  • registryEverything else: Context7, DeepWiki, Supabase, Stripe, Figma…
  • yoursGitHub and Vercel calls run with your own tokens: your private repos, your PRs, your quota.

Connect

Act as yourself: sign in with GitHub in the GPT, or pass your tokens as headers in any MCP client. Server tokens are never used on your behalf.

  • ChatGPTGPT with Actions from /openapi.json and GitHub OAuth, or developer-mode app at /mcp.
  • Claudeclaude mcp add --transport http rawmware <domain>/mcp --header "x-github-token: …"
  • CursormcpServers.rawmware = { url, headers: { x-github-token, x-vercel-token } }
  • HTTPPOST /api/tools/<tool> with JSON args.
